【大脑回答】在模拟世界实现《信号在自然界广泛存在》的第一步和困难：

第一步：**定义信号的最小单元**——一个"信号"需要三件事：①可观察（agent 能看到/听到）；②可发送（agent 能主动发出）；③有接收者（信号必须有"被解读"的预期）。先在世界上让一个 agent 能发出"嘀/嗒"两种符号，另一个 agent 能观察并记录。

三个核心困难（按出现顺序）：
1. **组合性**：蜜蜂舞蹈=有限信号（方向/距离），语言需要组合（有限符号→无限表达）——你的世界要先有"符号拼接"规则；
2. **对齐/约定**：信号的意义不是内建的，是接收者解码出来的——两个 agent 必须"对齐"同一套解码（这是语言最大的涌现难点，Project Sid 里宗教传播就是靠模板预置才出现）；
3. **诚信问题**：信号无代价时会撒谎泛滥（见 Q-0508 的代价理论）——需要让发送信号消耗资源，否则信号系统崩坏。
