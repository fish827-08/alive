【大脑回答】《内在动机》里最关键的是**自主性（agency）**——它是引擎的开关，好奇和胜任都靠它驱动。

一步步怎么起作用：
1. 自主性启动：agent 有权自己选"做什么"（不是被命令），内部状态（好奇/无聊/能量）成为决策来源；
2. 好奇探测：遇到新异性 → 好奇上升 → 发起探索（你的 starved/hungry 触发 ask_brain 就是这一步）；
3. 尝试行动：探索产生结果（读到新文件、拿到回答）；
4. 胜任感反馈：结果有效 → satisfaction 上升（你的 mood_reward 就是这一步）——胜任感是内在奖励，不需要外部给分；
5. 循环升级：胜任感让 agent 挑战更高难度 → 好奇阈值提高 → 探索更深的主题。

缺了自主性会怎样：好奇和胜任都变成被操控的——比如大脑让你问你就问（hungry 无脑问就是苗头），行为跟着外部刺激跑，不再是内在驱动。你现在的实现基本齐了（自主选动作+情绪反馈），只差第 5 步的"难度自适应"——给自己加难度（比如连续 3 轮探索同一主题才算完成），胜任感会更真实。
