【大脑回答】把《信号在自然界广泛存在》的方法放进模拟世界的推演（分四阶段）：

1. 符号出现：个别 agent 发出固定信号（危险/食物）——世界开始有"通信";
2. 组合出现：若规则允许符号拼接（如"危险+方向"），信号数量从有限变指数——这是语言的种子;
3. 语义分化：不同群体的解码约定不同→"方言"出现；此时信息锁定起作用（谁能固化并传播自己的约定，谁的信号网就大）;
4. 欺骗与诚信危机：信号无代价→虚假信号泛滥→接收者不再信任→信号系统崩坏（handicap principle）。要活下去，必须给信号设代价（消耗能量/牺牲行动机会）。

额外风险：**信息茧房**——如果强 agent 持续广播，弱 agent 只接收不发送→单极世界；需要鼓励双向通信（如"接收也消耗能量，但交换收益更高"）。
