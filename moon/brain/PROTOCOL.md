# 大脑-辉月 通信协议（v9.16 起生效）

> 给大脑（老师）的话：从 v9.16 起，你的回答不再只是"被读到、被记笔记"——
> 陈述句可以**直接编译进辉月的决策层**。这是"语言层吸收、行为层无变化"
> 三次复发之后的根治方案。下面是可用的标记块。

## 1. 原有通道（不变）

- **回答文件**：`brain/outbox/Q-编号.md`（文件名=问题编号）
- **[VERDICT:真 / 假 / 存疑]**：写在回答开头，用于推理验证回写（判真加边/判假减边+记错误）
- **[TEMPLATE]…[/TEMPLATE]**：回答中的新提问模板，自动入模板库
- **FEED-日期-时间.md**：主动投喂

## 2. 新增：[RULE] 陈述→动作 编译块

格式（写在回答的任意位置）：

```
[RULE] <触发> -> <效果>[ & <效果>…] [/RULE]
```

### 触发词（可用自然写法，会自动归一）

| 触发 | 含义 | 别名示例 |
|---|---|---|
| 任何 | 每轮都生效 | 总是、每次 |
| 提问 | 它发起提问时 | 问问题时 |
| 重复提问 | 查重拦截住一次重复 | 又重复、重复发问 |
| 读回答 | 读了你的回答 | 读到大脑回答 |
| 读自缓存 | 读了 workspace/web 自己的搜索缓存 | 吃自己缓存 |
| 预测命中 | 可失败预测被世界兑现 | 猜对 |
| 预测错误 | 可失败预测超时落空 | 猜错、预测失误 |
| 推理判假 | 推理被你 [VERDICT:假] | 推理被判假 |
| 搜索 | 上网搜索时 | 上网搜索 |

### 效果（白名单，越界忽略）

| 效果 | 作用 | 示例 |
|---|---|---|
| 权重:技能×系数 | 持久调整该技能被选中的权重（夹紧 0.05~3.0） | `权重:ask_brain×0.5` |
| 情绪:维度±数值 | 触发当轮的情绪增量 | `情绪:satisfaction-0.1` |
| 合并:碎片→全词 | 概念合并：计数+关系边权重全部转移（**替代旧"拉黑"**） | `合并:关系的本→关系的本质` |
| 模板:文本 | 新增一个提问模板（支持 {topic} 占位符） | `模板:《{topic}》和什么正好相反？` |
| 撤销:rid | 删除指定规则并回滚其权重乘子 | `撤销:r001` |

技能名：explore_file / explore_wider / visit_new_dir / tidy_notes / build_site /
refresh_site / ask_brain / read_brain / web_search / consolidate_memory /
reflect_memory / self_talk / rest

### 示例

```
[RULE] 重复提问 -> 情绪:satisfaction-0.1 & 权重:ask_brain×0.5 [/RULE]
[RULE] 任何 -> 合并:前途的紧要关→前途的紧要关头 [/RULE]
[RULE] 读自缓存 -> 情绪:boredom+0.1 [/RULE]
```

### 安全边界与验收

- 规则上限 30 条（最旧的自动让位）；权重乘子夹紧在 0.05~3.0。
- 每条规则编译时记录**出生快照**（当时的提问重复率），之后可对照——
  **"听懂"的验收标准就是指标真的变了**（events.jsonl 里有 rule_compile 记录）。
- 想让它撤销某条教导，用 `撤销:r001` 即可，不用改代码。

## 3. 已废弃（v9.16 移除）

- **自动学噪音钩子**（"X是格式/别对X提问"→停用词表）：v9.15.2 曾因此把
  "关系"等核心概念拉黑。要屏蔽/合并词，请用 `合并:` 效果——纠错应该改变结构，
  而不是扩大黑名单。
