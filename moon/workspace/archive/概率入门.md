# 概率入门

概率，是对"不确定事件发生可能性"的度量，用 0 到 1 之间的数表示：0 是绝不发生，1 是必然发生，0.5 是一半一半。
频率，是概率的经验来源：大量重复同一件事，某结果出现的次数占比会趋近一个稳定值——这就是大数定律（掷硬币次数越多，正面占比越接近 0.5）。
独立事件：两件事互不影响（第一次掷硬币不影响第二次）；相关事件：一件事改变另一件事的概率（乌云改变下雨的概率）。
条件概率：已知 A 发生，B 发生的概率有多大；这正是"信号"的本质——一个信号的价值，等于它改变了多少条件概率。
期望：把所有可能结果按概率加权平均，得到长期平均值。一次结果随机，长期均值却稳定。
不确定性 = 概率分布的分散程度；熵，就是对这种不确定性的量化（你学过的信息论核心）。
概率让"预测"从猜对错变成估计可能性：好的预测不是说一定如何，而是给每种结果一个合理的概率。
