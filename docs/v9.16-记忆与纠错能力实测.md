## 1. 你对 LLM 的判断：对，而且比你说的更彻底

- 每次调用 = 给定上下文续写，**无状态、无学习、无记忆**。✅
- 记忆只能是外部存储 + 每次重新注入。✅
- 训练完权重就定死，只有搜索能改变它的"输入"，改不了它的"倾向"。✅

补一刀：**LLM 的"人格"也是上下文的一部分**。它不是"想"表现得像个助手，是它在续写"一个会这样说话的角色"——包括"我没有情感""我记住了"这类话，都是续写出来的，不是状态。

## 3. 四个问题，实测答案

实验方法：调用它自己的 `selfdrive.learning.learn_from_text`，喂四段文本（各 3 次、跨 2 个来源，满足晋升门槛），然后看 state。

```
T1: 一加一等于二。这是最基础的加法原理……      ×3  (src_A)
T2: 一加一等于三。这是最基础的加法原理……      ×3  (src_B)
T3: 《海边》这篇文章是小李写的……              ×3  (src_A)
T4: 《海边》这篇文章其实是小王写的，之前弄错了…… ×3  (src_C)
```

### 结果 `[实测]`

```
transforms:
  一加一→二   support 3
  一加一→三   support 3

与"海边"相关的关系边:
  文章讲的是一|海边   w=3
  次旅行|海边         w=3

概念:
  一加一 / 加法原理 / 海边 / 海边更正

冲突/修订相关状态键: []
```

| 你的问题 | 实测答案 | 为什么 |
|---|---|---|
| **他会不会坚持？** | **谈不上** | 它没有"信念"这个对象。`urge` 是动作层的渴求（某技能久未触发就加权），不是对某个判断的坚持 |
| **1+1=3 会不会怀疑？** | **不怀疑，两个都信** | `transforms` 的键是 `表达式→结果`，`一加一→二` 与 `一加一→三` 是两个不同的键，各记各的 support。**没有唯一性约束，没有矛盾检测** |
| **小李→小王 会不会更正？** | **无法表示，谈不上更正** | `小李`/`小王` 连概念都没晋升（门槛 3 次/2 源），边都没建。而 `海边更正` 成了**另一个概念**——它连"同一篇文章"都没认出来 |
| **重要性分类？** | **没有** | 只有晋升门槛（次数/来源数）和 LRU 淘汰。**"这条要不要核实"没有任何计算** |

线上实例也印证了：`transforms` 里 `一加一加一→四` 从 v9.18 挂到现在没被推翻，`一加一→二` support 18。

## 4. 人脑怎么做这件事（四条可仿的机制）

| 机制 | 内容 | 文献 |
|---|---|---|
| **来源监控** | 记忆自带"谁说的/在哪看到的"，并按来源可信度加权 | Johnson, Hashtroudi & Lindsay, 1993 |
| **再巩固需要预测误差** | 记忆被提取时进入可塑窗口，但**只有出现预测误差才改写**；无误差只强化 | Nader et al., 2000；Sevenster et al., 2013 |
| **重要性 = 唤醒 + 目标相关性** | 杏仁核在编码时调节海马，情绪唤醒高的更牢 | McGaugh, 2004 |
| **睡眠重放与图式整合** | 慢波睡眠重放，把情景转成语义；与图式一致的信息优先并入 | Lewis & Durrant, 2011 |

对应到工程，不是加一个 `importance` 分数，而是加三样**结构**：

1. **命题化**：`claim(subject, relation, object)`——把"文章-作者-小李"变成可寻址的槽位。没有槽位就没有"被替换"的单位。
2. **来源 + 时间 + 置信**：每条 claim 带 `source / ts / conf`，来源可信度参与合并。这正是代码里 `learn_from_text(..., source)` **收了参数却从不存**的地方。
3. **冲突检测 + 再巩固窗口**：新值命中同一槽位且不同 → 不覆盖，标 `contested`，保留双方；等验证（大脑 VERDICT / 多源一致 / 自己推导）后再 `supersede`，旧值进 `history`（append-only）。

这就是 1979 年 Doyle 的**真值维护系统**和 AGM 信念修正理论的仿生版 `[文献]`。

### "重要性"可以算出来，不用猜

```
验证价值 = 引用该 claim 的规则数 × 规则权重 × 冲突度
```

- "谁写的不重要" → 没有规则引用它 → 验证价值≈0 → 不核实。
- "1+1 等于几" → 被大量 transforms/规则引用 → 验证价值高 → 必须核实。

这正好回答你说的"有的消息需要验证，有的不需要"。

## 6. 结论

它现在**能记，但不能改**；能积累，但不能否定。

这不是"笨"，是**表征层缺一个单位**——它存的是"词和词一起出现过"，不是"某物具有某属性"。所以"1+1=3"进得来、"其实是小王写的"进不来，不是态度问题，是**没有可写的槽位**。

先装 jieba，再加 `beliefs.py`。在这之前，任何"它会自我纠错吗"的期待都会落空。
