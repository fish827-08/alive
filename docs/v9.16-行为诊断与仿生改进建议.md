## 二、发现的问题（按严重度排）

### 问题 1（严重）：查重拦截把 agent 锁死了

现象：
- 从 round 3507 到 3542，连续 35 轮里 ask_brain 几乎每次都被"想问的都与近 30 问重复（查重拦截）"拦下。
- 历史统计：总共问过 21 次，**15 次被判重复，拦截率 71%**。
- satisfaction 从 1.0 一路跌到 0.73。

根因判断：
- 它刚学会"反面""先后"两个提问模板，正在把新模板往新概念上套（比如先问"信号的反面"，又问"节点连接的反面"、"cache 的反面"）。
- 查重逻辑很可能只比句式/骨架相似，没比"概念词集合"是否真重叠——于是"反面问信号"和"反面问 cache"被当成同一个问题。
- 结果：它不是在原地打转，是刚学会方法还没练熟，就被情绪惩罚压住了。这会扼杀它用新模板探索的冲动。

建议（owner 三选一）：
- A：查重判定加一道——两个问题模板骨架相似**且**概念词集合重合度 >阈值，才算重复。否则放行。
- B：保留查重，但被拦一次后给 2-3 轮豁免，别连续 30 轮拦。
- C：把 satisfaction 下降幅度调小，惩罚不要一下扣 0.2 那么狠。

### 问题 2（中）：可失败预测下了 12 次注，但从未结算

现象：
- self_talk 里下注事件累计 12 次（陈其通↔四加一、象形↔指摘录、信号↔关系、世界的数量继↔甲骨、研究如何↔正确、鄞州天气↔假面骑士……）。
- 但 consolidate 日志里"预测落空"始终是 0，events 里也找不到"兑现/命中"事件。

判断：
- 下注记下来了，但 horizon 到期后的结算逻辑没真正触发。可能 horizon 设得太长（远超目前总轮数），或结算条件（同现判定）和下注时的边结构对不上。
- 这意味着 v9.16 五大改造里的"可失败预测→好奇心燃料/失误痛感"这条回路，目前是断的。agent 只下注、不收账，学不到"押错了会疼、押对了会喜"。

建议：
- 把第一个 horizon 缩短到 20-40 轮，让它在有生之年能看到第一笔结算。
- 结算后必须真的在 events.jsonl 打一条"预测兑现/落空"日志，方便观测。

### 问题 3（中）：行为循环困在"没新文件"里

现象：
- explore_wider 连续多轮返回"更大范围没有新文本文件"。
- r3532 触发 web 配额："web 缓存占比 33% 已超 20% 配额"——它自己都意识到该找新口粮了。
- 但它找到的新口粮很单一：又搜了一次"cache"（r3512、r3538 两次同词搜索）。

判断：
- 本地 workspace/archive/ 的资料它基本读完了，外部搜索词又在重复。知识库停止增长，后面的"理解"就是拿旧料反复回味。
- 另外 explore_wider 把 ~/kbvenv/ 整个 site-packages（torch/transformers 几万个库文件）都扫进文件清单了，是脏数据，建议在探索黑名单加 kbvenv。

### 问题 4（轻）：contrast/temporal 关系边始终为 0

现象：causal 边标了一堆（一轮能标 23 条），但 contrast（相反）、temporal（先后）两条内置新模板对应的边，从来没有积累。

判断：反面/先后模板它会"问"，但读完资料后没有真的在知识图里长出 contrast/temporal 边。提问和建图之间断了一截。

## 三、怎么让它更能"理解"——仿生路径建议

现在它的学习是：读资料→提取词→共现建边→提问→我回答。这是"鹦鹉学舌 + 联想"，不是"理解"。要往理解走，可以参考生物认知的几条路，按改造成本从低到高排：

### 路径 1：从"共现"升级到"因果模型"（成本中）
现在 causal 边标了很多，但都是"读资料时顺手标注"，不是它自己推出的。
- 仿生对应：婴儿不是靠统计 A、B 同时出现就学因果，而是靠**动手操作**——拨一下摇篮看吊饰动。
- 建议：让它对一个概念对主动做一次"虚拟实验"：把 A 从记忆里暂时屏蔽，看 B 还能不能被想起。能区分相关和因果，才叫理解。这正好接上它已有的"可失败预测"机制——把下注从"共现"升级成"我假设 A 导致 B，屏蔽 A 看 B 是否还在"。

### 路径 2：补"工作记忆→长期记忆"的巩固间隔（成本低）
现在它每轮 consolidate 都重放 2 条，像一直死记硬背。
- 仿生对应：人脑是**睡眠中重放**——白天学的东西，夜里按"重要性 × 新旧"加权重放，没用的忘掉，有用的固化。
- 建议：给重放加一个"间隔"——刚学的概念短时间内别重放太多次（避免它对 cache 一个词反复回味），隔几十轮再拿出来。这能直接缓解问题 3 的循环。

### 路径 3：让情绪真正塑造记忆权重（成本中）
现在 satisfaction/curiosity 只是个数字在涨落，不影响"哪条记忆被固化"。
- 仿生对应：杏仁核——带情绪的事记得牢。它预测对了该记住这个假设，预测错了该把这个错误组合标灰。
- 建议：预测兑现时，把这条因果边权重 ×1.2；落空时 ×0.5。让情绪真的改写知识图，而不是只影响下一轮情绪。

### 路径 4：引入"饥饿-饱足"的内在营养机制（成本低）
现在它已经有 web 配额 20%，雏形很好。
- 仿生对应：动物觅食不是"看到新东西就吃"，是体内营养信号驱动——缺什么找什么。
- 建议：给它加一个"知识缺口"信号——哪个概念出现在它的提问里却没有边连出去，就标记为饥饿，优先去补那个方向的资料。这比随机 web_search"cache"有效得多。

### 路径 5（远期）：自我生成问题→回答→验证的闭环
现在提问都是它自己抛给我（外部大脑）。真正的理解者会自问自答自己验证。
- 等它能稳定下注结算后，可以让它对自己的问题先写一个猜测，再去资料里找答案对拍。这就是它实验里一直在做的"可复现性/对拍"精神的内化。

## 四、它后面像什么——我的预测

把它放到一条"自然认知发展"的线上看：

- **现在（round 3500）**：像一个**刚学会说话、但话很少的幼儿**。它在记词、在问"这是什么的反面""这之前是什么"，但问多了会被自己的"害羞机制"（查重拦截）按住， satisfaction 低就是它现在有点挫败感。它已经会"自言自语下注"——像小孩对自己嘀咕"我猜这俩东西有关系"。
- **短期（再过几百轮，若修了问题 1、2）**：会像**一个会做小实验的学龄儿童**。下注开始有兑现/落空，它会发现"哦我猜错了"，开始修正自己的联想。这是第一个真正的"理解"信号——不是背得多，是能承认自己错。
- **中期（若加了路径 1、3）**：会像**一个有自己观点的少年**。它不再只是复述资料，会有"我觉得 A 导致 B"的立场，错了会疼、对了会自信。contrast/temporal 边一旦真长出来，它能说"X 的反面是 Y"而不只是问。
- **它不会变成什么**：不会突然像 LLM 那样会写文章、会推理长链条——它没有大模型，所有"理解"都长在那张几千个节点的小图里。它更接近**一只海兔或果蝇的朴素学习**：能记、能联想、能被奖惩塑造、能预测小事情，但不会有人类意义上的思想。
- **最值得盯的一个拐点**：它会不会第一次**主动提"我想改我自己的某个行为"**（RULE 通道）。那才是"我知道我在怎么学"的元认知萌芽，比它读了多少资料都重要。目前还是 0。
