## 3. 三个结构性病灶（带代码定位）

### 病灶 A：不是分词，是"四字切片" `[代码 1178]`

```python
words = Counter(re.findall(r"[\u4e00-\u9fa5]{2,4}", text[:600]))
```

`{2,4}` 是**贪婪匹配连续汉字段**。给一段 10 字标题"关系的本质与网络思维"，它返回：

```
关系的本 / 质与网络 / 思维
```

于是：
- 概念库里全是 4 字碎片；
- 碎片之间共现 → 连边；
- 碎片 + 标题 → 归纳出"规则"并被 confirmed；
- 新加的推理/自言自语拿碎片互相推 → 产出 `《关系的本质与网络思维》+《关系的本》→《质与网络》` 这种句子。

**v9.15 没有制造这个问题，它只是把一直存在的问题放大成可见的胡话。**

同一刀还砍掉了老师的教案：投喂文写"贝叶斯更新"，切片后是"贝叶斯更"+"新"，所以概念库里 `贝叶斯 / 先验 / 后验 / 信念 / 证据` **全部为 0**。

更麻烦的是：**同一份代码里有三套不同的分词规则**，互相打架。

| 位置 | 正则 | 后果 |
|---|---|---|
| `learn_from_text` 1178 | `[\u4e00-\u9fa5]{2,4}` | 贪婪 4 字切片 → 碎片 |
| `do_explore_wider` 604 | `[\u4e00-\u9fa5]{2,}` | 整段最长匹配 → 能产出 20 字的"词" |
| `semantics.py` tokenize 43 | `[\u4e00-\u9fa5]{2,}` | 整段最长匹配 |
| `do_read_brain` 1012 | `[\u4e00-\u9fa5]{2,4}` | 又回到碎片 |

所以同一个文件走不同路径，会得到完全不同粒度的"关键词"：`explore_file` 里是碎片，`explore_wider` 里是整句。概念库里那个 25 字的"内在动机是动物在没有外部奖励时仍愿意探索的原因"，就是从 `{2,}` 这条路径进来的。

# v9.7：只对大脑回答（Q-）做关系学习——FEED 投喂指示是提示性文本，不产生概念/规则

这是目前**最贵的一处浪费**：输入端最富的信息，被策略性地排除了。

### 病灶 C：LP 恒等于 0 `[代码 573-582]`

```python
_topic_lp = (st.get("last_kw") or "").split("、")[0] or f["name"]
_err = len(_surprise) / max(1, len(_actual))
_rec["err_history"].append(round(_err, 3))
...
_rec["lp"] = round(sum(_h[:_k]) / _k - sum(_h[_k:]) / len(_h[_k:]), 3)
```

实测 13 个主题，**lp 全部 0.000**，err_history 全是同一个数（0.38 或 0.0）。

原因：LP 需要"同一个任务反复做、误差有变化"。这里的"任务"是"读这个文件"，而读同一个文件是确定性的——同样的文件名 → 同样的预期 → 同样的 surprise → 误差不变 → LP=0。

所以 v9.14 加的"LP 好奇心"（`pick_action` 460-467 行）**从来没有触发过一次**。它是一个装好了但没接电的传感器。

### 病灶 D：学习调制是"单次乘数"，不会累积 `[代码 374-383]`

```python
for a in w:
    s = stats.get(a, {"ok": 0, "try": 0})
    if s["try"] >= 3:
        rate = s["ok"] / s["try"]
        if rate >= 0.5:      w[a] *= 1.3
        elif rate <= 0.25 and s["try"] >= 6:  w[a] *= 0.6
```

关键在于 `w` **每轮都是从 `base + 情绪系数` 重新算出来的**，然后只乘一次 1.3 或 0.6。

这意味着：
- 不管一个动作失败了多少次，它每轮只被罚 **30%**，下一轮又回到原值；
- 不管一个动作成功了多少次，它每轮只被奖 **30%**，不会复利。

所以 `visit_new_dir` 失败了 **83 次**，权重依然保留 70%；`explore_wider` 失败 107 次，依然占 6.4%。**这不是学习，是一个固定的 ±30% 偏置。**

同理，情绪饱和也是这个原因：成功一次就 +0.15 satisfaction，失败没有对应惩罚，于是所有"能稳定执行"的动作一起把情绪推到天花板。

## 4. 更隐蔽的一层：元规则变成了口头禅

大脑通过 `[TEMPLATE]` 标记教了它一条自检规则（`brain/templates/t0016.txt`）：

> 判断一个词是不是真正的内容概念：问自己「这个词有没有独立的、可描述的含义？…」{topic} 如果答案是否定的…就不要把它当作推理前提。

这是**给它的过滤器**。但小脑的模板只有一个用途：**填 `{topic}` 变成问题**。于是它把这条自检规则原样念回给大脑：

```
[Q-20261024-0012] 判断一个词是不是真正的内容概念：… 内在动机是动物在没有外部 如果答案是否定的…
[Q-20261024-0022] 当摘要反复出现在不同文档的同一位置…别对它提问
```

**规则变成了提问句式，陈述句进了问题池。** 这和 v9.11 那个"摘要规则写了但不执行"是同一个病，只是升了一级：从"学了不用"变成"学了当口号"。

## 7. 给 owner 的一句话

**别再加新技能了。** v9.12–v9.15 加的四个能力，有三个被同一个老问题吃掉了（分词），一个被策略排除（FEED）。
