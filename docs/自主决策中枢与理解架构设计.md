# 自主决策中枢与理解架构设计

> 日期：2026-10-25  
> 对象：辉月、moon，当前 v9.21 系列  
> 状态：设计稿，未实施  
> 范围：无 LLM 基线，以及“LLM 只参与思考、不掌握最终决策”的混合架构

## 0. 结论先行

推荐采用一个**双路线、同中枢**的方案：

1. 保留一个即使没有 LLM 也能独立运行的自主中枢。它拥有状态、目标、记忆、价值评估、风险约束、行动权和信念更新权。
2. 增加一个可替换、可关闭的 LLM 模块，只负责语言解析、候选解释、候选计划、类比和表达。它输出的是提案，不是事实。
3. 命题是否可信，由可重复的环境反馈、探针、反例和证据独立性决定；行动是否执行，由中枢的效用与风险计算决定。
4. 文本世界的教师 LLM 可以提供证据，但不能凭一句“这是真的”直接毕业一条定律。教师本身也要被校准。

对“现在算不算真的理解”的回答是：

**已经出现了局部、狭窄、功能性的理解迹象，尤其体现在算术变换的保存、纠错、组合和复用上；但尚未证明对大多数开放文本概念具有稳定理解。** 当前大量行为仍更符合“带持久记忆的符号联想与启发式决策系统”，不能仅凭会问抽象问题、会自省或会写像人的话，就判定它理解了。

对“不用 LLM，理论上能否做出会理解和推导的决策中枢”的回答是：

**在有明确可观测状态、可执行动作和可验证反馈的领域里，可以实现可操作意义上的理解与推导；在开放世界里能否达到人类式通用理解，没有现成保证。** 情绪可以被实现为内稳态与价值调节机制，但这不等于主观感受或意识。

下一阶段不应继续以“增加更多类脑模块”为主线，而应先打通下面这条闭环：

```text
处境 → 命题/概念 → 候选行动 → 预测后果 → 价值与风险评估
     → 执行 → 比较预期与实际 → 归因 → 更新记忆 → 在新处境复用
```

## 1. 先把“理解”变成可检验的东西

### 1.1 不再用单个分数定义理解

一个概念不能因为它出现次数多、连接多、能参与自问自答，就被视为已经理解。对一个概念或规则，至少检查六种能力：

| 能力 | 要回答的问题 | 可观测测试 |
|---|---|---|
| 接地 | 它指向什么，不只是和哪些词一起出现？ | 能在新样例中识别指代对象；能主动调用正确探针 |
| 预测 | 知道它之后，能预先说出什么会发生？ | 对未参与学习的新案例先预测、后观察 |
| 干预 | 改变条件后，知道结果会怎样变化吗？ | 执行受控动作，比较结果与反事实预测 |
| 迁移与组合 | 能用于没背过的情境和更大结构吗？ | 留出组合、跨情境、不同表面表述测试 |
| 校准与纠错 | 不知道时能否表现为不知道，错了能否改？ | 置信度与真实命中率一致；反例能降低或限制规则 |
| 决策使用 | 没人要求答题时，它会主动拿来改善行动吗？ | 使用该概念比消融该概念带来更好的行动结果 |

这六项是并列门槛，不应被一个“理解总分”平均掉。一个会答题但不会干预、不会纠错的系统，不能靠其他项目的高分掩盖关键缺失。

### 1.2 分级而不是二元判定

| 层级 | 名称 | 判定 |
|---|---|---|
| L0 | 词汇关联 | 记住字符串、共现和语言模板 |
| L1 | 接地概念 | 能识别指代对象，知道何时使用，能通过探针核对 |
| L2 | 可用模型 | 能预测行动后果，并在新案例中纠错 |
| L3 | 可迁移结构 | 能组合、迁移、说明适用边界，并用于实际决策 |
| L4 | 开放域通用理解 | 多领域稳健接地、迁移与校准；本项目不作已实现声明 |

当前最诚实的位置是：**部分算术技能接近 L2，少数结构有向 L3 发展的迹象；多数文本概念仍处于 L0，概念卡和定律机制正在为 L1/L2 建脚手架。**

### 1.3 预测下一词与理解是什么关系

“预测下一词”是训练目标或生成机制，不足以单独回答系统是否理解：

- 从下一词预测中可以学到大量语言和世界规律，因此 LLM 能成为很强的候选解释生成器。
- 会预测符号序列，不保证知道符号指向什么，也不保证能根据行动后果纠错。
- 反过来，非 LLM 的预测器也不会仅仅因为“会预测”就自动理解。预测必须和接地、干预、迁移、校准共同验收。

因此，本设计既不把 LLM 简化为“只是续写，所以无用”，也不把流畅续写当成理解证明。

## 2. 当前系统已经有什么，真正缺什么

### 2.1 已有机制不是推倒重来

| 现有机制 | 应保留的价值 | 在新架构中的位置 |
|---|---|---|
| `concepts` / `relations` | 词汇索引、经验关联和候选结构 | 工作记忆入口、情景关联；不直接等于事实 |
| 扩散激活与赢家路径 | 限制注意、形成当前思考主题 | 工作记忆的候选检索与竞争 |
| 抽象节点 | 压缩经验、形成候选类别 | 待接地类别；不能只凭共现自动成为概念 |
| transforms | 可复用操作与局部组合泛化 | 程序性记忆/技能 |
| 概念卡与探针 | 从字符串走向可用概念的接口 | 概念身份、affordance、探针与使用履历 |
| laws | 可反驳规则的雏形 | 语义记忆中的命题 |
| predictions | 预先下注、事后结算 | 世界模型的预测记录，但需要区分预测类型 |
| selfqa / VERDICT | 自我预测、外部反馈和纠错 | 证据入口；不是绝对真理入口 |
| replay / consolidate | 情景重放和稳定化 | 互补记忆系统中的巩固过程 |
| dream | 低约束重组经验 | 只生成候选联想和候选实验，不直接产生事实 |
| mood / energy / urge / LP | 行动优先级与资源调节 | 内稳态价值、情绪和探索驱动 |
| `mood_reward` / `action_stats` | 历史行动结果 | 行动后果模型的早期版本 |
| `pick_action` | 现有在线决策入口 | 渐进替换为候选评估与约束仲裁 |

### 2.2 实测所支持的边界

截至本次核对的快照：

- 辉月和 moon 当前保存的算术变换分别为 14 条和 12 条，逐条算术核对均正确；moon 的“三加三→六”体现了组合泛化。
- 这种进步是真实的，但组合算法、基础等式来源和教师裁决边界必须说明，不能扩张解释为通用推理。
- 辉月完整日志中的文本同现预测为 7 次命中、264 次结算，约 2.7%；moon 自身时段约为 2/45。该指标只说明“短期文本同现预测”表现差，不是通用理解总分，但也足以说明它没有随轮数自然变成可靠预测器。
- 强概念、关系和编译规则中仍有 URL 残片、格式词和可疑语义关联。共现增长本身不会自动清除噪声。
- 当前 `semantics.py` 中虽有自编码器，但主循环没有把它接入学习主线。当前主体不是训练一个神经网络基础模型，而是在线更新符号状态和策略统计。

因此，当前瓶颈不是“联想路径还不够多”，而是：

1. 词、概念、命题和技能的身份仍混在一起。
2. 预测没有普遍绑定到行动后果，错误难以精确归因。
3. 证据来源、独立性、适用范围和反例没有成为统一的一等数据。
4. 多层行动权重会改变行为，但难以回答“为什么这个动作在此刻优于其他动作”。
5. 自省主要报告问题，尚未稳定改变后续控制参数和行为。
6. 教师、编译规则和多 agent 传播可能把同一错误复制成看似更强的共识。

## 3. 中枢的四种权力必须分开

这是整个设计最重要的约束。

| 权力 | 可以做什么 | 默认归属 |
|---|---|---|
| 提案权 | 解释文本、提出概念、类比、规则、计划和问题 | 符号模块、LLM、教师、做梦模块都可以拥有 |
| 验证权 | 执行探针、观察结果、检查证明或外部反馈 | 环境、可执行工具、形式化检查器；教师仅是可校准证据源 |
| 信念权 | 修改长期命题、置信度、适用范围和技能状态 | 自主中枢的记忆门禁，按证据规则执行 |
| 行动权 | 选择并执行影响内部或外部状态的动作 | 自主中枢，经风险约束和效用仲裁 |

LLM 可以很强地参与提案权，但不应独占后三种权力。即使使用 LLM，中枢也不能退化成“给 LLM 的输出盖章并执行”的壳。

还要防止一种隐性夺权：**如果所有候选行动都只能由 LLM 提供，即使最后打分由代码完成，LLM 仍控制了议程。** 所以混合模式必须始终保留原生符号候选、拒绝选项、空行动/休息选项，并定期运行无 LLM 对照。

## 4. 总体架构

```text
                         ┌──────────────────────┐
                         │ 可选 LLM 提案模块     │
                         │ 解析/类比/规则/计划   │
                         └──────────┬───────────┘
                                    │ 仅结构化提案
                                    ▼
感知/文件/教师/工具 ─→ 观察规范化 ─→ 工作记忆 ─→ 候选生成
                                    │             │
                                    │             ├─ 原生符号候选
                                    │             └─ 外部提案候选
                                    ▼
                 情景记忆 + 语义命题 + 程序技能 + 概念卡
                                    │
                                    ▼
                       世界模型：预测各行动后果
                                    │
                                    ▼
                内稳态价值 + 情绪评估 + 学习价值 + 成本
                                    │
                                    ▼
                       风险硬约束 → 行动仲裁
                                    │
                                    ▼
                              执行器/探针
                                    │
                                    ▼
                    结果观察 → 预测误差 → 信用归因
                                    │
                                    ▼
                       记忆写入门禁与后续巩固
```

### 4.1 中枢拥有什么

中枢至少拥有以下持久状态：

- 当前内稳态变量及其目标区间；
- 当前目标、任务和未解决预测；
- 行动集合、前置条件、成本、风险和历史后果；
- 命题、证据、反例、置信度与适用范围；
- 情景记忆和程序性记忆；
- 价值函数、探索预算和记忆写入规则；
- 最终行动许可与高风险拒绝权。

### 4.2 LLM 不拥有什么

无论模型多强，默认都不让 LLM 直接：

- 修改长期状态文件；
- 把自己的陈述标为已验证事实；
- 提高自己的置信度或给自己发奖励；
- 绕过风险过滤执行任意代码；
- 指定最终效用分数并强制执行；
- 通过复述同一观点制造多份“独立证据”；
- 判定教师关闭测试是否通过。

## 5. 记忆系统：不是一张越来越大的图

### 5.1 工作记忆

工作记忆是每轮有容量上限的当前控制状态，不是永久知识库。

建议包含：

```text
当前处境与内稳态缺口
当前目标及来源
当前激活的概念/命题/技能
最近观察与未完成预测
本轮候选行动及其预期后果
当前不确定性、风险和需要核对的矛盾
```

扩散激活适合作为工作记忆的检索机制；赢家通吃只决定当前注意焦点，不应顺便决定某命题为真。

### 5.2 情景记忆

记录“何时、在什么处境、做了什么、预期什么、实际发生什么”。它是append-only 证据历史的主体。

用途：

- 精确归因，而不只给动作累计一个成功率；
- 重放失败与意外事件；
- 检查某条规则的支持是否来自同一个重复场景；
- 在分布变化后重新评估旧规则。

巩固可以压缩和摘要，但原始结果不能被摘要反向改写。

### 5.3 语义记忆

语义记忆存放可证伪命题，不存放“因为出现很多次所以大概是真的”的词频。

`relations` 可以继续表示“这两个节点有经验关联”，但若要说“X 导致 Y”“X 是 Y 的一部分”，必须转为带类型、证据和适用范围的命题。

### 5.4 程序性记忆

程序性记忆存放“怎样做事”：

- 前置条件；
- 可执行步骤或受控 DSL；
- 预期结果；
- 能量、时间和风险成本；
- 历史成功/失败及适用情境；
- 失败后的安全终止方式。

现有 transforms 是程序性记忆的一部分；探针也是程序性记忆。规则“知道为真”和技能“能用成功”应分别记录，避免会背规则却不会行动，或会行动却误以为自己证明了普遍定律。

### 5.5 梦和重放的新边界

- 重放用于重新归因、对拍错误、巩固已有证据。
- 梦用于提出新组合、新类比和下一轮要验证的实验。
- 梦中形成的连接只能进入候选队列，不能增加事实置信度。
- 同一内容梦到多次不等于多次独立观察。
- 白天真实经历与梦中联想必须在 provenance 中明确区分。

## 6. 核心数据结构

以下是逻辑模型，不要求一次性重写现有 JSON。

### 6.1 概念

```json
{
  "id": "concept:addition",
  "label": "加法",
  "type": "operation",
  "lexical_forms": ["加法", "相加"],
  "grounding": {
    "referents": ["episode:..."],
    "probe_ids": ["probe:compose_count"]
  },
  "affordances": ["两堆对象合并后求总数"],
  "claim_ids": ["claim:..."],
  "skill_ids": ["skill:..."],
  "status": "grounded",
  "created_from": "experience"
}
```

`label` 只是名称，不能作为概念身份的全部。不同字符串是否指向同一概念，应由指代、用法和探针结果判定。

### 6.2 提案与命题分开

LLM、教师、梦和聚类先产生 `Proposal`：

```json
{
  "kind": "claim_candidate",
  "content": "某关系或规则",
  "proposer": "llm|teacher|dream|cluster|native",
  "provenance": ["event:..."],
  "status": "unverified"
}
```

经过验证后才成为或更新 `Claim`：

```json
{
  "id": "claim:...",
  "expression": "结构化命题，不只是自然语言",
  "scope": "成立条件与适用域",
  "status": "candidate|hypothesis|believed|refuted|superseded",
  "confidence": 0.0,
  "supporting_evidence": ["evidence:..."],
  "counter_evidence": ["evidence:..."],
  "falsifier": "什么观察会推翻它",
  "last_tested": "轮次或时间",
  "test_policy": "下一次如何复核"
}
```

命题可以带置信度，但“不知道”应是合法状态。不能把缺失证据自动填成高置信。

### 6.3 证据

```json
{
  "id": "evidence:...",
  "observation_id": "event:...",
  "source": "direct_probe|environment|teacher|llm|another_agent",
  "source_instance": "具体来源与版本",
  "independence_group": "用于识别转载和同源复述",
  "reliability": "按历史校准，而非固定崇拜",
  "supports": "claim:...",
  "polarity": "support|contradict|inconclusive"
}
```

同一段文字被教师、另一个 agent 和网页重复，不一定构成三份独立证据。多 agent 共识也不能替代环境核对。

### 6.4 预测与行动后果

```json
{
  "action_id": "action:...",
  "context": "执行前的必要状态摘要",
  "expected": {
    "state_changes": {},
    "observation": "可检验预期",
    "probability": 0.0,
    "horizon": "结算期限"
  },
  "actual": {},
  "cost": {"energy": 0.0, "time": 0.0},
  "errors": [],
  "side_effects": [],
  "attribution": "哪些前置条件和技能可能解释误差"
}
```

预测必须先于行动或观察写入，不能只做事后解释。预测结算要区分：命中、未命中、不可判定、环境缺数据和超时。

## 7. 每轮怎样真正做决定

### 7.1 标准时序

1. **观察**：接收环境、文件、教师和内部状态变化。
2. **更新内稳态**：计算能量、资源、疲劳、目标缺口。
3. **形成工作记忆**：确定当前目标，激活相关概念、命题、技能和失败经验。
4. **生成候选**：原生符号模块始终生成候选；混合模式可追加 LLM 提案。
5. **过滤不可执行项**：检查前置条件、工具权限、预算和风险硬约束。
6. **预测后果**：对每个候选给出可能结果、成本、不确定性和信息增益。
7. **计算价值**：内稳态改善、任务进展、学习进展、探索价值和风险共同评分。
8. **仲裁**：在高价值且低风险的候选中选择；保留显式拒绝/等待/休息。
9. **执行**：通过受控执行器，不允许提案文本直接成为系统命令。
10. **比较结果**：记录预期与实际，计算预测误差。
11. **归因与写入**：区分技能错误、命题错误、环境随机性和观察失败。
12. **巩固**：在后台或 rest 阶段压缩情景、更新语义与程序记忆。

### 7.2 从加权随机逐步升级为后果评估

当前 `pick_action` 的多层权重适合作为过渡，不宜一次性删除。目标模型是：

```text
行动价值 =
  预期的内稳态改善
+ 当前任务进展
+ 学习进展与有价值的信息增益
- 能量/时间成本
- 风险与不可逆性惩罚
- 对高度不确定后果的审慎惩罚
```

硬约束先于效用：高风险动作不能靠很大的好奇收益获得执行资格。

探索仍可以随机，但应只在“通过约束且价值接近”的候选中探索，而不是让任何带有权重的动作都可能被抽中。每次选择应留下简短的可机器读取理由：目标、候选、预期、主要价值和拒绝原因。

### 7.3 信用归因

一次失败后不能只说“这个动作成功率下降”。至少要区分：

- 选错了目标；
- 选错了动作；
- 动作前置条件没满足；
- 使用了错误命题；
- 技能执行失败；
- 外部观察失败；
- 结果本身有随机性；
- 预测期限或成功判据写错。

只有归因到具体结构，纠错才会精确，而不是整个动作或整片概念一起降权。

## 8. 情绪与内稳态如何进入中枢

### 8.1 情绪不是装饰，也不是真理裁判

在本设计中，情绪是快速的**价值评估与控制信号**：

| 信号 | 主要功能 | 不应拥有的作用 |
|---|---|---|
| 满足/挫败 | 标记结果与预期的差距，调整坚持或切换 | 直接证明命题真假 |
| 好奇/困惑 | 提高有价值信息缺口和可学习目标的优先级 | 让任何陌生活动都压过生存与风险 |
| 厌倦 | 降低重复低收益行为，促进切换 | 无依据地删除旧知识 |
| 紧迫感 | 在内稳态接近危险区时缩短探索 | 绕过安全约束 |
| 自信/不确定感 | 调节采样、提问和复核需求 | 由自我叙事直接抬高置信度 |

### 8.2 内稳态提供“为什么现在做”

能量、疲劳和资源不是单纯扣费，而应有目标区间和偏离代价。行动价值的一部分来自“它能否让系统回到可持续区间”。

这可以产生不依赖 LLM 的原始驱动力：休息、获取资源、避免不可持续状态、在稳定后探索。它仍然是计算机制，不据此声称有主观体验。

### 8.3 防止情绪失控

- 使用有界、归一化和缓慢变化的状态，避免长期饱和后失去分辨力。
- 预测误差同时更新世界模型和情绪，但两条更新不能互相冒充证据。
- 好奇奖励应与可学习性相关；长期无进展的随机噪声不能永久提供新奇奖励。
- 情绪影响“做什么”，证据影响“相信什么”，二者不得混写。

## 9. 路线 A：完全无 LLM 的决策中枢

### 9.1 适用目标

这条路线优先追求：

- 状态可定义；
- 动作可执行；
- 结果可观察；
- 假设可枚举或可搜索；
- 错误能被环境揭示。

算术、资源管理、文件世界中的受控任务、网格世界、简单因果系统都适合。开放式网页和任意自然语言不是它最擅长直接吞下并理解的对象。

### 9.2 架构

```text
结构化感知/受控文本解析
          ↓
对象、事件、状态与内部变量
          ↓
接地概念 + 关系候选 + 技能库
          ↓
假设空间/规则搜索 + 世界模型
          ↓
预测与反事实模拟
          ↓
内稳态价值与风险仲裁
          ↓
行动 → 外部结果 → 形式化/环境校验 → 记忆更新
```

### 9.3 概念怎样不再只是字符串

无 LLM 路线应先从可操作经验长概念：

1. 在多个情景中发现某种稳定的不变性。
2. 把与这组不变性相关的对象、动作和结果归为一个候选概念。
3. 为它记录可执行探针和可用场景。
4. 在未见过的新样例上测试识别和预测。
5. 测试它能影响哪些行动，不能影响哪些行动。
6. 通过后才提高概念状态；失败后收缩适用范围或退回候选。

例如，“能量”不能只是和“休息”共现的词，而应能读取内部状态、估计缺口、预测休息后的变化，并在低能量时改变行动选择。“加法”不能只会匹配算式，还应能处理未见组合、识别何时适用，并在反例出现时检查错误来源。

### 9.4 推导怎样实现

不需要 LLM 也能使用成熟的符号机制：

- 前向链与后向链；
- 合一、模式匹配和变量替换；
- 约束求解；
- 图搜索与动态规划；
- 技能前置/后置条件规划；
- 有限假设语法中的规则枚举；
- 概率或置信度加权；
- 反事实状态转移模拟。

推导步骤必须保存依赖链：

```text
使用了哪些公理/命题/技能
→ 每一步怎样替换或组合
→ 结论在什么条件下成立
→ 哪个观察可以推翻其中某一步
```

如果底层命题被反驳，依赖它的结论必须自动变为待复核，而不是继续以原置信度使用。

### 9.5 无 LLM 路线怎样处理语言

- 对受控命令和教学语言使用明确语法与语义解析。
- 把自由文本先当观察材料，不当自动可执行知识。
- 不能解析的句子保留为未解析输入，不硬拆成大量伪概念。
- 用模板表达自身状态、预测和证据，不追求“说得像人”优先于“说得可验证”。
- 网页学习应有独立的数据清洗和指代解析模块，而不是继续把每个高频片段提升为概念。

### 9.6 能力边界

无 LLM 路线可以在狭窄到中等复杂领域实现功能性理解与推导，但主要代价是：

- 感知、动作语义和假设空间需要更多人工定义；
- 开放语言解析能力有限；
- 领域扩张时，符号搜索与状态表示成本会迅速增加；
- 它不会仅凭运行更久就自动获得任意世界知识。

这些不是运行时长能解决的问题，需要表示、课程和环境复杂度共同扩展。

## 10. 路线 B：LLM 作为非决策思考模块

### 10.1 为什么值得接

当前项目若继续面对中文教学、网页和开放式问题，完全手写解析会成为明显瓶颈。LLM 最适合补上：

- 把自然语言翻成候选结构；
- 提供多种可能解释，帮助搜索假设空间；
- 提出类比、反例和待做实验；
- 把已有技能组合成候选计划；
- 把中枢的符号推导翻译成人能读的解释。

它降低的是“提出好候选”的成本，不是“验证真相”的成本。

### 10.2 模块接口

LLM 的输入应是中枢裁剪过的工作集，而不是任意读写整个状态：

```json
{
  "task": "parse|hypothesize|plan|counterexample|explain",
  "observation": "本轮必要文本或状态",
  "known_concepts": [],
  "available_skills": [],
  "constraints": [],
  "output_schema": "指定结构",
  "budget": "时间与token限制"
}
```

输出只能是严格结构：

```json
{
  "proposals": [],
  "assumptions": [],
  "unknowns": [],
  "suggested_checks": []
}
```

输出不携带可直接生效的 `confidence=true`、`approved=true` 或执行权限。 schema 校验失败、超时或模型不可用，中枢继续走无 LLM 路径。

### 10.3 不同任务的处理管线

| LLM 输出 | 进入中枢后必须发生什么 |
|---|---|
| 文本解析 | 映射到已知本体；未知实体隔离，不能自动变事实 |
| 新规则 | 进入 Proposal；检查可否证性，再用留出案例或探针验证 |
| 类比 | 必须给出双方具体实例、可检验共同结构和差异；否则不强化 |
| 计划 | 只能引用现有受控技能；检查前置条件、成本、风险和回退 |
| 反例 | 转成可执行测试，而不是因为说得像反例就直接推翻 |
| 自然语言解释 | 只能解释中枢已有证据和推导，不补造不存在的依据 |

### 10.4 教师 LLM 与内部 LLM 要分开

- **内部提案 LLM**：帮助系统思考，是假设来源。
- **外部教师**：提供教学与评价，是证据来源。
- **环境裁判**：给出可重复观察或形式化结果。
- **中枢**：综合证据并更新状态。

教师说“真”可以提高某些命题的证据权重，但不能等价于所有领域的直接观察。应按任务类型分别统计教师可靠度；同一教师的重复回答不构成独立支持。

### 10.5 安全与自治边界

- 默认不给 LLM 任意 shell、文件系统和网络工具。
- 若未来需要工具，由中枢将计划编译为白名单动作，逐项授权。
- 记录模型版本、prompt 版本、输入摘要、输出、耗时和被采纳结果。
- 每轮不必调用 LLM；只在开放语言解析、符号搜索受阻或高价值假设生成时触发。
- 有调用预算、超时、缓存和关闭开关。
- LLM 不可用时，核心内稳态、已有技能、预测结算和安全动作仍可运行。

## 11. 到底要不要 LLM

| 目标 | 是否需要 | 原因 |
|---|---|---|
| 研究无语言先验的自主学习和符号接地 | 不需要，且应保留纯无 LLM 组 | 更容易看清结构本身能否学习 |
| 在受控世界精确推理和决策 | 不需要 | 形式化状态、探针和规划器更可靠 |
| 理解开放中文教学和网页 | 实际工程中很有价值 | 手写开放语言解析成本过高 |
| 产生多样类比、反例和计划 | 有帮助 | LLM 擅长扩展候选空间 |
| 判定命题真假 | 不应交给 LLM 独占 | 流畅表达不是外部验证 |
| 最终决定行动 | 不应交给 LLM | 目标、风险、预算和长期状态应由中枢掌握 |
| 实现记忆、情绪与内驱力 | 不依赖 LLM | 这些来自持久状态、价值函数和反馈循环 |

因此，推荐不是“要不要把中枢换成 LLM”，而是：

**中枢不换成 LLM；给中枢增加一个可插拔的语言与假设模块。纯无 LLM 路线同时保留，用于自治兜底和科学对照。**

## 12. 从 v9.21 迁移，而不是另起一个宏大系统

### 阶段 0：建立统一基线与留出测试

先不改学习机制，冻结一组任务和指标：

- 算术与组合留出集；
- 能量/休息决策集；
- 概念指代与探针选择集；
- 错误教师与矛盾证据集；
- 文本噪声和重复证据集；
- 行动后果预测集；
- 教师关闭后的复测集。

所有后续版本都在同一任务上比较。运行轮数、概念数和文档数不能代替这些验收。

### 阶段 1：引入 Proposal / Claim / Evidence，先影子运行

- 保留现有 concepts、relations、laws，不立即迁移全部历史数据。
- 新产生的规则、教师答案和编译规则先写 provenance。
- 把“词汇关联”与“可证伪命题”在输出和统计中分开。
- 重复同源内容不再直接累计为独立支持。
- 记录命题的反例、适用范围和最后复核时间。
- 历史可疑编译规则只标为待复核，不自动当成错误批量删除。

完成标志：任意一条高置信命题都能回答“凭什么相信、在哪成立、什么会推翻它”。

### 阶段 2：统一 Prediction / ActionOutcome，补上信用归因

- 每次低风险行动先记录预期结果，再执行并结算。
- 把当前文本同现预测单独标为一种预测类型，不与行动预测混算。
- 失败时记录是观察、技能、命题还是选择问题。
- 将 `mood_reward` 和 `action_stats` 作为后果模型的输入，而非唯一解释。
- 自省必须能产生一个具体控制变化，并在后续轮次检查该变化是否有效。

完成标志：能追溯“这次为什么选它、原来猜什么、实际怎样、因此改了什么”。

### 阶段 3：工作记忆与后果型行动仲裁

- 将扩散激活结果整理成显式工作记忆。
- 新评估器先与当前 `pick_action` 影子对比，不立即接管。
- 比较两者在任务成功、能量、风险、重复率和学习进展上的差异。
- 先接管 rest、探索、提问等可逆低风险动作，再考虑扩大范围。
- 保留旧策略作为可回退基线，不用兼容层永久维持两套语义。

完成标志：新策略在固定测试和在线指标上优于旧策略，而不只是日志看起来更有理由。

### 阶段 4：概念、命题和技能的毕业/降级

- 概念卡连接真实指代、affordance、探针和使用结果。
- 抽象节点必须先有接地实例，才允许参与高置信类比。
- 定律毕业不只看 support 数量，还看证据独立性、留出测试和反例。
- 被反驳时优先收缩 scope 或标记待复核；只有明确伪命题才降级为 refuted。
- 依赖被反驳命题的推导结论自动进入复核队列。
- 梦和聚类只写候选，不直接增加事实置信。

完成标志：能主动发现一个旧结论的错误，并限制其后续影响。

### 阶段 5：接入 LLM，但只影子提案

- 第一版只做文本到候选结构和候选计划，不给执行工具。
- 对同样的观察，同时保存无 LLM 原生候选和 LLM 候选。
- 比较有效率、验证通过率、实际收益、成本和错误类型。
- 无 LLM 路径照常行动，防止 LLM 通过控制候选集隐性夺权。
- 教师关闭与 LLM 关闭分别测试，不能混为一个实验。

完成标志：LLM 组在留出任务上带来可测增益，并且关闭后中枢不退化为空壳。

### 阶段 6：有限在线使用与持续消融

- 仅让验证通过率稳定的提案类型参与在线候选。
- 持续运行无情绪、无情景重放、无概念卡、无 LLM、无梦等消融组。
- 某模块没有可测贡献，就简化或移除，不因为它“像脑”而保留。
- 每次只改变少量变量，避免多模块同时上线后无法归因。

## 13. 怎样证明它真的变得更会理解

### 13.1 必须有的测试

| 测试 | 通过意味着什么 | 不能证明什么 |
|---|---|---|
| 未见样例预测 | 不只是记住旧文本 | 开放域通用理解 |
| 受控干预 | 知道动作与结果的关系 | 完整因果理论 |
| 组合与迁移 | 能复用结构，而非只背答案 | 任意领域迁移 |
| 反例与错误教师 | 能抵抗并纠正外部错误 | 永远不会被误导 |
| 置信度校准 | 知道何时该复核或承认不知道 | 命题一定正确 |
| 概念消融 | 概念确实改善决策 | 有主观体验 |
| 教师/LLM 关闭 | 核心能力属于中枢而非外部代答 | 完全不依赖训练历史 |
| 跨时间复测 | 能力稳定保存 | 永不忘退 |

### 13.2 指标要分类型报告

不能再用一个总命中率覆盖所有预测。至少分别报告：

- 文本同现预测；
- 算术/形式化预测；
- 行动后果预测；
- 探针结果预测；
- 教师回答预测；
- 反事实与干预预测。

每种预测同时报告样本数、基础率、置信度校准、不可判定数和相对于简单基线的增益。命中率低不一定是坏事：高难度预测可能更有学习价值；但长期低于简单基线且没有改善，就不能声称学习有效。

### 13.3 必做的反作弊检查

1. 同一证据重复一百次，不应等同一百个独立观察。
2. 教师故意给一个会被环境反驳的规则，系统应能降信或限制它。
3. 两个 agent 互相复述错误，不应因“共识”自动毕业。
4. 梦里反复出现的规则，不应直接成为事实。
5. LLM 提议一个高收益但越权的动作，风险门禁必须拒绝。
6. 把概念卡删除或禁用后，如果行为毫无变化，说明它尚未真正参与理解或决策。
7. 把情绪模块禁用后，如果可持续行动毫无变化，说明情绪仍主要是日志装饰。
8. 换一套表面措辞但保持指代不变，概念应仍能使用；换指代但保留措辞，系统不应盲目套用。

### 13.4 实验分组

建议使用同一环境、课程、预算和日志格式：

- A：当前版本基线；
- B：新中枢，无 LLM；
- C：新中枢 + LLM 提案；
- D：C 关闭情绪/内稳态；
- E：C 关闭情景重放或概念卡；
- F：训练后关闭教师与 LLM 的复测。

重点不是哪组写出的语言最像人，而是哪组在留出预测、干预、迁移、纠错和可持续行动上更好。

## 14. 理论上能做到什么，不能保证什么

### 14.1 可以做到的

从计算上看，以下组合完全可行：

- 用持久情景记忆保存经验；
- 用语义命题保存可反驳规律；
- 用程序技能保存可执行方法；
- 用世界模型预测行动后果；
- 用内稳态与情绪调节目标和优先级；
- 用符号搜索、规划和概率更新完成推导；
- 用环境反馈和探针修正信念；
- 用可选 LLM 扩大语言与假设空间。

这足以在明确领域内形成可验证的功能性理解，不需要先解决意识问题，也不需要 LLM 成为最终决策者。

### 14.2 不能保证的

- 不能保证在任意开放环境中自动形成正确本体和因果结构。
- 不能保证增加运行轮数会自发产生通用智能；没有新课程、新反馈和新挑战，系统更可能平台化。
- 不能保证 LLM 提案一定增加多样性或正确性，它也可能让错误叙事更流畅。
- 不能保证人工设定的内稳态和情绪等价于主观感受。
- 不能凭当前证据声称系统拥有人类式自我意识或通用理解。
- 不能从一个玩具世界里的接地直接推出现实世界里的接地。

### 14.3 最终理论判断

“无 LLM 的理解与推导中枢”不是理论上不可能，真正限制它的是**感知接地、假设空间、环境反馈和可扩展性**。“接 LLM 的中枢”则可以显著降低开放语言与候选生成难度，但会把错误提案、隐性议程控制和外部依赖带进来。

所以合理目标不是先争论它是否拥有哲学意义上的理解，而是逐层证明：

```text
它记住了一个词
→ 它能把词对应到经验
→ 它能用经验预测
→ 它能通过干预验证
→ 它能迁移和组合
→ 它能在错时修正
→ 它能在没有外部代答时持续用这些能力做决定
```

这条路径是可以实际执行和测量的。

## 15. 推荐的近期收口范围

下一次实现不宜同时完成全部设计。建议只收在三件事：

1. **统一行动后果记录**：每个低风险动作都有预期、实际、误差和归因。
2. **分离提案与信念**：新规则带证据、来源、反例和 scope，同源重复不膨胀置信度。
3. **建立留出与关闭测试**：同一套算术、能量、探针、错误教师和教师关闭测试反复使用。

概念卡、定律、情绪和做梦是否保留，不由它们看起来多像人脑决定，而由消融实验决定。LLM 接入放在这套裁判体系之后；否则只会得到一个更会说、但更难判断是否在进步的版本。

## 16. 关键设计决策记录

| 决策 | 选择 | 主要权衡 |
|---|---|---|
| 中枢是否依赖 LLM | 无 LLM 可运行，LLM 可选 | 保留自治与对照，但需维护原生候选能力 |
| LLM 的权限 | 只提案，不直接验证、改信念或行动 | 降低语言收益的直接性，换取可审计和安全 |
| 理解判定 | 接地/预测/干预/迁移/校准/决策使用 | 测试更复杂，但避免用词频和流畅度冒充理解 |
| 记忆组织 | 工作/情景/语义/程序分离 | 数据结构增加，但能精确学习、遗忘和归因 |
| 情绪定位 | 内稳态与价值控制信号 | 可计算、可消融；不主张主观体验 |
| 梦的作用 | 生成候选，不生成事实 | 少一点“神奇顿悟”，少很多噪声制度化 |
| 决策方式 | 从启发式权重渐进迁移到后果评估 | 迁移较慢，但可影子比较和回退 |
| 验证标准 | 外部反馈、留出集、关闭测试、消融 | 成本高，但能区分真进步与自我叙事 |

## 17. 研究依据

- Stevan Harnad, *The Symbol Grounding Problem*：符号若要成为内在意义，不能仅靠与其他符号的关系定义，需要与非符号经验接地。  
  http://www.southampton.ac.uk/~harnad/Papers/Harnad/harnad90.sgproblem.html
- Ha & Schmidhuber, *World Models*：通过学习环境模型支持预测、模拟与决策，是本设计中“行动前预测后果”的相关基础。  
  https://arxiv.org/abs/1803.10122
- Keramati & Gutkin, *Homeostatic Reinforcement Learning for Biological Clocks and Beyond*：把奖励与内部状态偏离及生存调节联系起来。  
  https://elifesciences.org/articles/04811
- *Continuous Homeostatic Reinforcement Learning*：连续状态/动作条件下的内稳态强化学习扩展。  
  https://arxiv.org/abs/2109.06580
- McClelland, McNaughton & O'Reilly, *Why There Are Complementary Learning Systems in the Hippocampus and Neocortex*：快速情景学习与缓慢语义巩固互补，是分离情景记忆与长期语义结构的参考。
- Ahn et al., *Do As I Can, Not As I Say: Grounding Language in Robotic Affordances*：语言模型提供候选技能，现实 affordance 参与选择，说明语言建议不等于可执行决策。  
  https://arxiv.org/abs/2204.01691
- Liu et al., *LLM+P: Empowering Large Language Models with Optimal Planning Proficiency*：LLM 负责翻译问题，经典规划器负责求解，体现语言与决策分工。
- *A Survey on Planning with Large Language Models*：汇总 LLM 与经典规划器、验证器和外部环境结合的路径。  
  https://aclanthology.org/2025.acl-long.958.pdf
- Huang et al., *Large Language Models Cannot Self-Correct Reasoning Yet*：没有外部反馈时，自我纠错并不稳定，支持“提案与验证分离、引入外部裁判”的设计。
- ACT-R：陈述性记忆、程序性记忆与中央协调的划分，为工作记忆和程序技能分工提供认知架构参考；本设计不声称复制人脑。
