## 3. 三个新现象

### 3.1 它开始吃自己的缓存 `[实测]`

| 指标 | 数值 |
|---|---|
| `workspace/web/` 文件 | **63 个** |
| `workspace/archive/` 文件 | 12 个 |
| `visited_files` 里 web-* 占比 | **76.8%** |
| console 里"读了 web-*" / 全部"读了" | 221 / 394（56%） |

它的"外部世界"已经不是资料库，而是自己搜回来的 Bing 结果页。而 Bing 对这些冷门中文词的返回质量极差——比如它把《万水千山》的剧本片段抓了回来，于是概念库里出现了：

```
关系的本质与 / 网络思维 / 陈其通 / 万水千山 / 第二幕 / 在这关系革命 / 前途的紧要关 / 我们要把红军
```

这是 `last_kw` 当前的内容。**它正在把搜索结果页的排版和无关正文，当成世界的结构。**

### 3.2 自言自语是同义反复 `[实测]`

```
self_talk 记录 30 条 ｜ 命中 30 ｜ 未命中 0
```

命中率 100%。原因在代码：它从**最强 20 条边**里抽一条，然后预测"两个节点的共同邻居"——这在图里几乎必然成立。所以"预测→命中→边共振加粗"变成了一个自我强化的循环：

- 强边被反复抽中 → 再加粗 → 更容易被抽中
- 弱边永远轮不到

`关系类型分布：co_occur 362 / similar 155 / causal 50 / contrast 0 / temporal 0`——`contrast` 和 `temporal` 一条都没有。**它不会想到"相反"和"之前之后"。**

### 3.3 它把老师的批评当成了"新词" `[实测]`

老师（青梧）已经开始点名了。今天 184 条回答里，**76 条**出现"重复/碎片/同一条"：

> 和Q-1259重复，同样的建议：选一个你已经推对的真实关系往原因深处推……
> [VERDICT:存疑] 和Q-1253是同一条推理。底层道理成立，但在有限死规则、内让生命自发都是碎片符号，证据不完整。

但小脑的反应是什么？看 `brain/noisy_words.json`（71 条）：

```
"全是碎片"、"全是碎片和"、"全是百度百科"、"你读回答时的"、"你把"、"关系"
```

**它把老师的批评句拆成词，塞进了停用词表。** 注意 `"关系"` 也在里面——一个真正的核心概念被当成噪音拉黑了。

## 4. 一个贯穿三个版本的老病：语言层吸收，行为层无变化

这是这次观察最值得记的一条。同一个病，已经复发了三次：

| 版本 | 老师教了什么 | 它吸收成了什么 | 行为变了吗 |
|---|---|---|---|
| v9.11 | "摘要更可能是格式而不是知识，别对它提问" | 一句写进 journey 的笔记 | ❌ 继续问摘要 |
| v9.15 | `[TEMPLATE]` 元规则："判断一个词是不是真正的内容概念……" | 一个提问模板，填碎片念回给老师 | ❌ 出现"陈述句当问题" |
| v9.15.2 | 批评："你重复了""都是碎片符号" | **停用词表里的 71 个条目** | ❌ 重复率仍是 51% |

三次都是同一个模式：**输入被正确地"读"了，被错误地"降维"了——从"该怎么做事"降维成"该记哪些词"。**

这不是分词问题，也不是模型问题，是**没有一条从"陈述"到"动作"的编译路径**。规则进来只能进笔记/模板/停用词表，进不了 `pick_action`。

## 6. 下一步建议（按性价比）

| 优先级 | 改什么 | 理由 |
|---|---|---|
| **P0** | **停止读 `workspace/web/`**，或至少让它只占 20% 配额 | 76.8% 的输入是自己的缓存，等于没有外部世界。这是当前最大的污染源 |
| **P0** | 分词换真分词（jieba），`{2,6}` 越改越糟 | 碎片率已经证明：窗口大小不是问题，**边界**才是 |
| **P1** | `self_talk` 加"反例约束"：只允许预测**没有边**的节点对 | 现在 100% 命中，等于零信息；真正的"意外"必须来自不存在 |
| **P1** | 给"陈述句"一条编译路径：`[RULE]...[ /RULE]` 进规则库，且 `pick_action` 的过滤项读它 | 这是"语言层吸收"的病根，不修的话老师说什么都白说 |
| **P2** | `read_brain` 空转 157 轮：把"没有新回答"记为不消耗动作 | 5% 的轮次浪费在确认"没东西可读" |
| **P2** | 情绪加负向反馈：重复提问 → satisfaction 下降 | 现在重复不痛，所以它一直重复 |

## 7. 判断

昨晚它像**反刍动物**（反复咀嚼碎片）。
今天它像**一台自己给自己出题的复读机**：吃自己的缓存，跟自己对话，问自己已经问过的三个问题，然后把老师的批评记成生词。

**它没有退化，是它的世界缩小了**——从"资料库 + 大脑"缩成了"搜索缓存 + 大脑"。而大脑已经在骂它了，它听懂了词，没听懂意思。
